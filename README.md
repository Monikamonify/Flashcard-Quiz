# Recall — Flashcard Quiz App

An interactive, responsive flashcard application created for the CodeAlpha App Development Internship, Task 1.

## Features

- Click-to-flip question-and-answer flashcards, with a show/hide answer control
- Previous and Next card navigation, plus keyboard arrow-key support
- Add, edit, and delete flashcards
- Progress indicator and empty-deck state
- Browser local storage, so a user's deck remains after refreshing
- Responsive, accessible interface

## Run locally

Open `index.html` in any modern browser. No installation or build step is required.

## Technologies

HTML, CSS, and vanilla JavaScript.
